# Marwan Al Hooti Portfolio Website

This is a simple personal portfolio website built with HTML and CSS.

## How to open it

1. Extract the ZIP folder.
2. Open the folder called `marwan_portfolio_updated`.
3. Double-click `index.html`.
4. The website will open in your browser.

## How to edit it

- Open `index.html` to change the text and sections.
- Open `style.css` to change colours, spacing, and design.
- The profile photo is inside the `images` folder.
- The resume PDF is inside the `docs` folder.

## Main sections

- Home
- About Me
- Education
- Projects
- Honours & Awards
- Skills
- Contact
